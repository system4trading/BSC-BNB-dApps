6. Before multisig signing

  • Verify chain ID is 97 and verify the Safe address independently.
  • Inspect every target, native value and calldata selector.
  • Confirm the nonce and Safe transaction fields using the actual Safe contract/UI.
  • Collect Safe-compatible transaction signatures and execute through the Safe contract or trusted Safe interface.
No private keys are requested by this app. Wallet connection is only used to display the account/network; transaction broadcast is intentionally not implemented.
Local-only package handling. CDN libraries and custom dApp previews still require network access. Never import a package and approve it without independent verification.
