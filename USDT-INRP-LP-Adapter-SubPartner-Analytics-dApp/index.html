Event scan results are cached locally in this browser. Cache is specific to the adapter address and selected scan data.
Historical charts are based on events returned by your RPC provider for the scanned block range. Some public RPCs cap block ranges, log response size or historical access. If a scan fails, reduce chunk size or use an archive-capable RPC. A partial scan is labelled as partial and must not be interpreted as full-period history.

This is a read-only analytics dashboard. It does not submit transactions. Contract aggregate getters represent lifetime on-chain totals; period charts are reconstructed from logs. Partner fee figures from getPartnerStats are contract-reported cumulative values; event scans provide historical activity only within the scanned block range.
